# T-map - Карта живого города

Тепловая карта городской активности на основе обезличенных транзакционных данных.  
Видишь в реальном времени - где сейчас людно, где пусто, где аномальный ажиотаж.

---

##  Возможности

- **Тепловая карта** - горячие и холодные зоны по числу транзакций прямо сейчас
- **Фильтры по категориям** - еда, развлечения, шоппинг
- **Popup по зоне** - количество транзакций и средний чек района
- **Аномалии** - маркер, когда активность в месте выросла в 2+ раза выше нормы
- **Лента событий** - новые отзывы, акции заведений, всплески активности
- **Страница заведения** - описание, фото, рейтинг, отзывы, «сколько людей сейчас»
- **Личный кабинет бизнеса** - редактирование страницы, акции, программа лояльности с QR
- **Авторизация** - JWT с refresh-токеном; публичные страницы доступны без входа

##  Быстрый старт

### Требования

- Node.js ≥ 18
- npm ≥ 9

### Установка

```bash
# Клонируй репозиторий
git clone https://github.com/AmenEpistat/T-map.git

# Установи зависимости
npm install
```

### Запуск

```bash
npm run dev

# Сборка для продакшена
npm run build

# Превью продакшен-сборки
npm run preview
```

---

##  Линтинг и форматирование

```bash
# Проверить всё сразу (ESLint + Stylelint + Prettier)
npm run check

# Исправить ESLint-ошибки автоматически
npm run lint:fix

# Исправить стили автоматически
npm run lint:styles:fix

# Отформатировать весь код
npm run format

# Проверить TypeScript без сборки
npm run type-check
```
